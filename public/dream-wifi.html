    This searches observations already reported by devices in the field. It does not scan radio networks remotely or establish a tunnel to a source by itself.

    The tracker cannot identify phones connected to a remote router or turn an unaware phone into a relay. A source must run an explicitly authorized agent. For a phone without the Dream Wi-Fi app, see the standalone source-agent limitations; captive/paid Wi-Fi needs the native Android source mode and a real portal test.

    For Quant Wi-Fi, connect to the network and complete the provider’s own login/package/payment flow in its portal before testing internet access. Dream Tunnel does not activate a package or bypass the provider’s access controls.

    A tunnel requires an authorized source endpoint and a reachable remote endpoint. Mobile data or another network can carry the encrypted tunnel but may incur charges. Software cannot create a radio link or internet access without a real transport path. Live package sales remain disabled until a real provider API and purchase flow are verified.
