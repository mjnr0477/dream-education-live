# Dream Education — Design system

- Audience: learners, teachers, parents and schools; Kenya-first with global reach.
- Primary job: help a learner start learning quickly while keeping teaching, school, AI Lab and Connect one tap away.
- Palette: Midnight Navy #050B24, Royal Blue #071B58, Electric Cyan #19C8FF, Aqua #75F1FF, Learning Yellow #FFD21A, White #F4F8FF.
- Typography: DM Sans for readable interface copy; Manrope for display headings.
- Layout: editorial learning hero with a CSS-built knowledge globe; six compact destination cards; focused search surface; mobile bottom navigation.
- Signature: a luminous knowledge globe made from cyan latitude/longitude lines.
- Behavior contract: this stylesheet is presentation-only. Existing data-action/data-panel controls, app.js, APIs, auth, learner state and workspace scripts remain authoritative.
- Accessibility: visible focus, high-contrast actions, safe-area-aware bottom navigation, reduced-motion support, responsive card grids.
